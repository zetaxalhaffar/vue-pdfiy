# Introduction

<span class="vuepdfiy-colorized">VuePDFIY</span> is a **Client-side** component for **Vue 3** that allows you to flexibly render PDF pages within your project. This library wraps pdf.js library so all main features of pdf.js are supported by <span class="vuepdfiy-colorized">VuePDFIY</span> as well, and uses [vue-pdf](https://tato30.github.io/vue-pdf/).
